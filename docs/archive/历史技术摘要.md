## 一、大厅协议契约（仍有价值，未入 STATE.md）

### 1.1 武器皮肤挂载 `mountGrid`

- 客户端发送：`mountGrid(mountId, "weaponSkinAppearance", targetId)`；登录时发 `mounts("weaponSkinAppearance", "")` 拉取已挂载项。
- **强制契约**：`StorageProxy.callbackMounts(param1, param2, param3)` 要求 `param3` 是**含 `"default"` 键的 Map**（值为 `List<MountUserBean>`）。返 List 会被解析成 null，`weaponSkinAppearanceDic` 永远为空，皮肤挂不上。
- 已在 `_work/lobby_host/java/LobbyLoginServer.java` 按此形状实现。

- 存储文件：`_work/lobby_host/user_profile.json`。

### 1.3 `NewMainView` XML 与 AIR Error #1009

### 1.4 Tag 76（SymbolClass）**绝不能剥离**

### 1.6 双窗口拓扑与 3D 展台

- 官方 AIR 是**透明宿主壳 + 动态 `NativeWindow` 视口**双窗口；`<transparent>true</transparent>` 的第一个窗口故意不显示。
- 禁止用 Win32 给根窗口加 `WS_CAPTION`/`WS_EX_APPWINDOW`，会破坏 AIR 双窗口消息循环与 DirectX 上下文（表现为闪退 `0xFFFFFFFF`）。
- 左侧 3D 角色/武器展台由 `UnityLobby\3\UnityLobby.exe` 嵌入视口完成（`ServersLogic.as` 的 `openUnityLobby`），不是 Flash 内渲染。
- `launch_lobby.py` 的 `MicroServer`（16397）在连接后需要按客户端 `saveStage lobby_load_res_compele` / 主视图就绪再发 `microSetVisible`，提前 0.5s 发送会导致黑屏（见 STATE.md §7.0.52）。

> **已被 STATE.md 推翻的旧结论**：三份旧文档把中央「正在加载资源…」遮罩归因于 `AirAloneChat.exe` 僵尸进程阻塞心跳；STATE.md §7.0.11 已实证真因是 `FLUI_ASSETS` 的内嵌 DoABC 挂住 AVM。僵尸进程清理仍建议保留，但**不是**该问题的根因。

## 二、客户端 / 战斗侧避坑（未入 STATE.md 的部分）

### 2.1 不要推进 `SeqId`（高危）

`PlaybackInitSystem` 在离线模式（`setting.TurnOn == true`）本来每帧执行。推进 `SeqId` 会连带 `PredicationInitSystem` 每帧判定预测误差并回滚 → **鼠标无法转视角**。

### 2.2 构建与注入

- `inject_rebuild.py` 读的是 `bin/Debug`：必须 `dotnet build -c Debug`，Release 产物不会被注入。
- `ilspycmd -r` 会让部分程序集崩 `0xC0000409`，去掉 `-r`。
- `Assembly-CSharp.csproj` 的 `HintPath` 是打包机路径，先跑 `python Game-SSJJ/tools/gen_rebuild_csproj.py` 重新生成。
- 源码是 CRLF/LF 混行尾，批量替换前先归一化，否则静默失败。
- UnityPy 会把 TextAsset 的 GBK 按 UTF-8 解坏 → 用 `raw_data` 手工解析。

### 2.3 三套坐标（与 STATE.md §6 同一契约，此处是具体函数级映射）

| 空间 | 表达式 |
|---|---|
| 快照 / 物理（厘米） | `PlayerEntityData.(X,Y,Z)`，Z 为高度 |
| `OfflineBotPhysics.Cast` 入参 | `(-data.Y, data.Z, data.X)` |
| Unity 表现（米） | `GetUnityPos(data)` = `(-data.Y/100, data.Z/100, data.X/100)` |

混用会出现「落点镜像到地图另一侧」「射线永远被墙挡」。

### 2.4 Bot 模型不显示的排查结论（旧 AI 已删除，但结论仍可用于新 bot 实装）

- 已排除：包缺失、网格塌陷（`SkinnedMeshRenderer.BakeMesh` 包围盒正常）、`Renderer.isVisible`（该值包含阴影相机，不可作为"颜色相机画了它"的证据）。
- 未排除且方向最可信：**服务端会下发、而本地快照没填的字段/实体**（`ModuleNames`、`PlayerPartEntityData`、`IsBot`、`EType`、`Alpha/SelfAlpha`、`AccessoryList`、`DyeingColor`）。
- 旁证：在线模式下其他玩家模型显示正常，说明「非本人玩家」渲染链路本身可用。

### 2.5 环境限制（本机）

- `Popen` 直接拉 exe 会在命令结束时被回收 → 日志停在中途且无 error。用 `_work/hold_game.py` 后台常驻。
- `schtasks` / WMI `Win32_Process.Create` / `WScript.Shell` 全被安全策略拦，不能用来脱离进程树。
