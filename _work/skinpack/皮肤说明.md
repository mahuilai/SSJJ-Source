# 自定义皮肤包 · 三国周瑜女（sanjiaozhouwoman）

给《生死狙击》离线战斗客户端换角色贴图用的资源包。只换这一个角色的皮肤，不动代码、不动武器、不动地图。

## 装法

1. 先把游戏关掉（进程 `SSJJ_BattleClient_Unity.exe` 不能开着，文件会被占用）
2. 把本压缩包解压到**任意位置**（不要解压进游戏目录，装完可以删）
3. 双击 `install.bat`
4. 看到 `安装完成` 就好了

脚本会自动找游戏目录（从解压位置向上找 `battle\3_64\SSJJ_BattleClient_Unity.exe`，也会试 `D:\SSJJ-4399`、`C:\SSJJ-4399`）。找不到会让你手动输路径。

## 进游戏怎么看到这个角色

脚本会自动把 `launch_config.json` 改成这个角色：

```json
{
  "career": "sanjiaozhouwoman",
  "hand": "woman"
}
```

原配置备份在同目录 `launch_config.json.skinbak`。进游戏按 **F3** 切第三人称就能看到。

## 它改了什么

| 路径 | 动作 |
|---|---|
| `...\AssetBundles\Windows\player\sanjiaozhouwoman_52ec316c...` | 新增（自定义贴图，330 KB） |
| `...\AssetBundles\Windows\player\sanjiaozhouwoman$2_e9245a58...` | 新增或覆盖（网格包，116 KB） |
| `...\AssetBundles\Windows\AssetBundles` | 改 `player/sanjiaozhouwoman` 的 md5 指向自定义包 |
| `AssetBundles.skinbak` | 清单原文件备份 |
| `prepare_launch_assets.py`（如果找得到） | 加 `PROTECTED_BUNDLES`，防止启动器把 md5 改回官方值 |

只碰这 4 处，其他一概不动。

## 两个必须知道的点

**1. 包必须放 `player/` 子目录。** 放在 `Windows\` 根目录会报
`Could not find file ...\Windows\player\sanjiaozhouwoman_xxx`，
表现是**角色模型整个不渲染，第三人称看不见人**。这个坑踩过，脚本已经处理对了。

**2. 别用会重写清单的启动器。** 如果他的启动器（`prepare_launch_assets.py`）没被脚本找到并打上保护，那么用启动器启动时会把 md5 改回官方值，皮肤就“消失”了。判断方法：进游戏后看 `log\offline.log` 里有没有

```
Loading Asset Bundle player/sanjiaozhouwoman  [[  md5 52ec316c...
```

是 `52ec316c` 就对了，是 `757c4a3c` 说明被打回去了，得再跑一次 `install.bat` 或手动改清单。

## 卸载

清单备份是 `AssetBundles.skinbak`，把它改名覆盖回 `AssetBundles` 就恢复原版皮肤。自定义包文件留着不影响，不会被加载。

## 版本要求

客户端必须是同一版本（`1.0.1.674`，Unity 2019.4.14f1）。贴图格式是 DXT1 512×512、8 级 mip，和原包一致，别的版本不保证。
